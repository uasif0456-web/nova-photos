## 2026-11-22 — Stage 1–2 repo reconnaissance COMPLETE

- Deliverable: `IMMICH_REVERSE_ENGINEERING_REPORT.md` (417 lines, ~57 KB). Investigation clone at `research/immich` (shallow, commit 9b3d3d86, 2026-11-21), version **3.4.0-rc.0**, AGPL-3.0. No code copied into any app project.
- Headline findings:
  - Server: NestJS 12 + Express 5, 3 workers (api / microservices / maintenance), port 2283, base `/api`; Kysely + Postgres 14 (pgvector), 106 migrations.
  - OpenAPI spec `open-api/immich-openapi-specs.json` v3.1.0, **202 paths** — single source of truth for the API.
  - Auth three-way: session cookie (`immich_access_token`, mobile login flow), scoped API key (`x-api-key`), shared-link key.
  - Upload: single multipart `POST /assets`, NOT chunked; dedup via SHA-1 (`x-immich-checksum` + `POST /assets/bulk-upload-check`); 200 = duplicate, 201 = created.
  - Media URLs: `GET /assets/{id}/thumbnail?size=thumbnail|preview`, `/original`, `/video/playback` (byte-range), HLS stream.
  - Jobs: BullMQ + Valkey, 20 queues; thumbnails sharp, video ffmpeg, EXIF exiftool, thumbhash placeholders.
  - ML sidecar (FastAPI, ONNX: OpenCLIP/SigLIP, InsightFace-derived faces, RapidOCR) — server-side; NOVA gets face/CLIP/OCR via API for free.
  - Mobile is LOCAL-FIRST: timeline from Drift (SQLite) mirror fed by `POST /sync/stream` (JSON Lines + `/sync/ack`), Socket.IO (`/api/socket.io`) as invalidation trigger. Server-side `GET /timeline/buckets|bucket` still exists.
  - Mobile connection: `/.well-known/immich` discovery → `GET /server/ping` → login → session. Dart client is generated (openapi-generator-cli 7.26.0), regenerated at build.
  - Background backup is the hard part: Android native Kotlin workers + Pigeon + Rust native_core — not pure Dart.
- Design consequences for NOVA: generate Dart client from the spec (pin version, feature-gate on `/server/version` + `/server/features`); timeline as local-first Drift mirror + sync-stream (MVP may start with `/timeline/buckets`); upload = SHA-1 + bulk-check + multipart; background backup is its own workstream.
- Gaps (report §13): static inspection only — no server run, no live API calls; some DTO fields, server↔ML contract, face-model filenames, offline failure paths not fully verified. Live verification is a Stage-3 task.

- Auth: Bearer JWT (login, no refresh token in spec), `immich_access_token` cookie, or `x-api-key` with granular scopes. Only `GET /server/ping` is unauthenticated. Recommendation: login + securely-stored JWT for the mobile app.
- Key gotchas for the build:
  - No `GET /assets` list endpoint — list via `POST /search/metadata` or time buckets.
  - Albums no longer embed assets in v3 — fetch via search with `albumIds`.
  - `SearchAssetResponseDto.total` deprecated — page with `nextPage`/`nextCursor`.
  - Video `duration` is a string in v3 (was a number in v2).
  - No `DELETE /assets/{id}` (bulk only), no `GET /trash`, no "devices" API at all (sessions only).
  - Error shapes and rate limits NOT documented in the spec (no 429 anywhere).
  - Upload: single multipart POST, `POST /assets/bulk-upload-check` pre-flight, 200 = duplicate / 201 = created.
  - WebSocket is Socket.IO at `/api/socket.io/` (not in spec; event list from official web client's `websocket.ts` — auth handshake flagged verify-live in Stage 4).
  - Timeline buckets marked `Internal` in the spec.
  - PUT→PATCH migration announced for v4/v5; 125 deprecated schema fields.
- Version compatibility: target `>= 3.0.0`, develop against 3.4.2. v3.0.0 (2026-07-02) was the breaking major. Feature detection via `GET /server/version` (`featureLevel`) + `GET /server/features`; block major < 3, warn on major > 3.
- MCP: **no official Immich MCP exists.** 10 real third-party MCP servers verified (JoeRu/mcp4immich 282 tools, okopok/immich-mcp 276 tools, drolosoft/immich-photo-manager 94 tools best-tested, lidless-labs/immichctrl, barryw/ImmichMCP, whitehara/immich-mcp, snickery/immich-library-mcp, mattmaas/immich-mcp, pimpmypixel/immich-mcp-server stale, wanjau2/Immich-MCP-server partially verified). Recommendation: **do NOT integrate any MCP server into NOVA v1** — REST API directly; MCP is a reference/future AI-assistant option (drolosoft or mcp4immich first).
- Unknowns flagged (not guessed): error JSON shape, rate limits, upload size cap, exact Socket.IO auth handshake, featureLevel→feature mapping, exhaustive v3.0 removed-endpoint list — all for live verification in Stage 4.
